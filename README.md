# SmartShop

A simple static e-commerce landing page built with HTML, CSS, and JavaScript.

## Overview

`SmartShop` is a responsive storefront prototype that showcases a hero section, product categories, featured products, and a contact form. It includes a responsive navigation menu and basic add-to-cart feedback using JavaScript.

## Features

- Responsive navigation menu with mobile toggle
- Hero section with background image and call-to-action
- Category cards for product grouping
- Featured product cards with image, price, and add-to-cart button
- Contact form layout
- Responsive styles for desktop and mobile

## Files

- `index.html` — main page markup
- `style.css` — styling and responsive layout
- `script.js` — JavaScript for menu toggle and add-to-cart alerts

## Usage

1. Open `index.html` in a web browser.
2. Click the menu icon on smaller screens to open the navigation.
3. Click `Add to Cart` on any product to see a confirmation alert.

## Notes

- The project is static and does not include a real shopping cart backend.
- Placeholder images are used for product visuals.
- The contact form is not wired to a server.
